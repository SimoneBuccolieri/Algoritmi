📜 TESTO DIDATTICO — CONCETTI CHIAVE E CONFRONTO PARADIGMI
Si vuole calcolare il valore del n-esimo numero di Fibonacci F(n), definito dalla ricorrenza: F(0) = 0, F(1) = 1, F(n) = F(n-1) + F(n-2) per n ≥ 2. Confrontare l'esecuzione Naive (senza DP, O(2^n)), la Memoizzazione Top-Down con tabella memo[] (O(n)) e la Tabulazione Bottom-Up iterativa con ciclo for (O(n)).
💡 CONCETTO CHIAVE: FIBONACCI (Memoization vs Bottom-Up)
Ricorrenza: F(0) = 0, F(1) = 1  |  F(n) = F(n-1) + F(n-2) per n ≥ 2
• 1. Naive (Senza DP): Calcola a cieca. Per F(5) ricalcola F(3) 2 volte e F(2) 3 volte. Chiamate tot: 15! ❌
• 2. Memoizzazione (Top-Down): Parte da F(n) e scende. Salva ogni F(k) calcolato in memo[k]. Se lo ri-chiedono, risponde subito in O(1) (HIT!). 🟢
• 3. Bottom-Up (Iterativo): Parte da F[0]=0, F[1]=1 e con un semplice ciclo for i=2 to n riempie la tabella da sinistra a destra. 🔵

📜 TESTO REALE D'ESAME — Appelli 02/07/2024, 19/09/2024 e 24/01/2025 (Esercizio 2)
"Siano dati due vettori a componenti intere a, b ∈ Zn. Si consideri la quantità c(i, j), con 0 ≤ i ≤ j ≤ n-1, definita come segue:
c(i, j) = ai se 0 < i ≤ n-1 e j = n-1;   |   bj se i = 0 e 0 ≤ j ≤ n-1;   |   c(i-1, j) · c(i, j+1) se 0 < i ≤ j < n-1.
Si vuole calcolare la quantità m = max{c(i, j) : 0 ≤ i ≤ j ≤ n-1}.
(a) Scrivere un algoritmo iterativo bottom-up per il calcolo di m e mostrarne la matrice popolata."
RICORRENZA (sempre visibile)
c(i, n-1) = a[i]             // caso base: ultima COLONNA → prendi a[i]
c(0, j)   = b[j]             // caso base: prima RIGA → prendi b[j]
c(i, j)   = c(i-1, j) * c(i, j+1)  // caso ricorsivo: usa la cella SOPRA e quella a DESTRA
Ordine di scansione: riempi prima l'ultima colonna (i=0..n-1), poi la prima riga (j=0..n-2), poi scorri colonne da destra a sinistra (j=n-2 downto 0), righe dall'alto al basso (i=1..n-1).

📜 TESTO REALE D'ESAME — Appelli 14/02/2024, 04/07/2025 e 10/09/2025 (Esercizio 2)
"Data una stringa X = ⟨x1, x2, ..., xn⟩, si consideri la quantità ℓ(i, j) definita per 1 ≤ i ≤ j ≤ n:
ℓ(i, j) = 1 se i = j;   |   2 se i = j-1 e xi = xj;   |   2 + ℓ(i+1, j-1) se (i < j-1) e (xi = xj);   |   maxk { ℓ(i, k) + ℓ(k+1, j) } se (i < j-1) e (xi ≠ xj).
(a) Scrivere una coppia di algoritmi INITL(X) e RECL(X, L, i, j) per il calcolo memoizzato di ℓ(1, n)."
RICORRENZA l(i,j) — Appello 04/07/2025 (sempre visibile)
l(i,j) = 1                              // CASO BASE: i == j (singolo carattere)
l(i,j) = 2                              // CASO BASE: i == j-1 e X[i] == X[j]
l(i,j) = 2 + l(i+1, j-1)           // X[i] == X[j] e j > i+1 → scava dentro
l(i,j) = max_k { l(i,k) + l(k+1,j) }  // X[i] != X[j] → prova tutti i tagli k
Come funziona INITL: inizializza tutta la matrice a NIL.  |  Come funziona RECL(X,L,i,j): se L[i][j] != NIL → restituisci subito (HIT!). Altrimenti calcola e salva.

📜 TESTO DIDATTICO & PROBLEMA CLASSICO — LIS (Longest Increasing Subsequence)
Dato un array A = <a1, a2, ..., an> di numeri interi, trovare la lunghezza della più lunga sottosequenza strettamente crescente.
Ricorrenza: L[i] = 1 + max({ L[j] : 0 ≤ j < i e A[j] < A[i] } ∪ {0}). Il risultato è maxi L[i].
