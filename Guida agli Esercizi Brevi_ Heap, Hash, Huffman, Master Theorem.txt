PARTE I - HEAP E CODE DI PRIORITÀ
Definizioni e Rappresentazione
Heap = Albero binario quasi completo implementato come array con proprietà:
• Max-heap: A[i] ≥ A[Left(i)] e A[i] ≥ A[Right(i)]
• Min-heap: A[i] ≤ A[Left(i)] e A[i] ≤ A[Right(i)]
Navigazione Array:
• Radice: A[1]
• Parent(i): A[⌊i/2⌋]
• Left(i): A[2i]
• Right(i): A[2i+1]

Metodo della Divisione
h(k) = k mod m
Regole di Progettazione:
• m primo, non vicino a potenze di 2
• Evitare m = 2^p (considera solo p bit meno significativi)
Metodo della Moltiplicazione
h(k) = ⌊m(kA mod 1)⌋
Valore suggerito: A = (√5-1)/2 ≈ 0.618034
Gestione Collisioni
Chaining (Concatenamento)
• Ogni slot contiene lista concatenata
• Fattore di carico: α = n/m
• Complessità attesa: O(1 + α)
Open Addressing
Linear Probing: h'(k,i) = (h(k) + i) mod m
• Problema: Clustering primario
Quadratic Probing: h'(k,i) = (h(k) + c₁i + c₂i²) mod m
• Requisito: c₁,c₂ appropriati per garantire permutazione
Double Hashing: h'(k,i) = (h₁(k) + i·h₂(k)) mod m
• Requisito: h₂(k) coprime con m
• Migliore distribuzione tra i metodi
Esempi Tipici Esame
Double Hashing m=8, h₁(k)=k mod 8, h₂(k)=1+2(k mod 6)
Inserimento [13, 29, 19, 27, 8]:

• k=13: h₁(13)=5, slot libero → posizione 5
• k=29: h₁(29)=5, occupato, h₂(29)=1+2(29 mod 6)=1+2·5=11 mod 6=5 → (5+1·5) mod 8 = 2 →

Funzione Non Appropriata: h(k,i) = (k + 2i) mod m
• Problema: Se m=10, k=0 genera sequenza 0,2,4,6,8,0,2,4,6,8...
• Non permutazione completa di {0,1,...,m-1}
Hash Uniforme e Proprietà Speciali
Invarianza per Permutazioni
h(k) = k mod m con m = 2^p - 1 è invariante rispetto a permutazioni delle p-word che costituiscono k.
Dimostrazione per Induzione:
• Base k=0: Banale
• Passo k→k+1: Usando n = a_{k+1}b^{k+1} + n', si dimostra che n mod (b-1) = (a_{k+1} + n' mod
(b-1)) mod (b-1) = Σ_{j=0}^{k+1} a_j mod (b-1)

Tre Casi Fondamentali
Caso 1: f(n) = O(n^{log_b(a)-ε}) per ε > 0
Risultato: T(n) = Θ(n^{log_b(a)}) Intuizione: Costo dominato dalle foglie dell'albero di ricorsione
Caso 2: f(n) = Θ(n^{log_b(a)})
Risultato: T(n) = Θ(n^{log_b(a)} · log n) Intuizione: Costo bilanciato tra livelli
Caso 3: f(n) = Ω(n^{log_b(a)+ε}) per ε > 0 E af(n/b) ≤ cf(n) per c < 1
Risultato: T(n) = Θ(f(n)) Intuizione: Costo dominato dalla radice
Esempi Risolti dagli Esami
T(n) = 4T(n/2) + n log n
• a=4, b=2, f(n)=n log n
• n^{log_b(a)} = n^{log_2(4)} = n²
• f(n) = n log n = O(n^{2-ε}) per qualsiasi ε < 1
• Caso 1: T(n) = Θ(n²)
T(n) = 4T(n/2) + n^{5/2}
• a=4, b=2, f(n)=n^{5/2}
• n^{log_b(a)} = n²
• f(n) = n^{5/2} = Ω(n^{2+1/2})
• Condizione regolarità: 4(n/2)^{5/2} = n^{5/2}/√2 ≤ cn^{5/2} per c=1/√2 < 1
• Caso 3: T(n) = Θ(n^{5/2})
T(n) = T(n-2) + 2n (Non Master Theorem)
Metodo di Sostituzione: Ipotesi: T(n) ≤ cn²
quando 4c - 2 ≥ 0, ovvero c ≥ 1/2.
Metodi Alternativi

PARTE V - INDUZIONE FORTE
Quando Usare Induzione Forte
Induzione Normale Fallisce quando il passo induttivo richiede informazioni su più valori precedenti, non
solo n-1.
Principio dell'Induzione Forte
Base: P(0) (o P(1)) è vera Passo: Se P(k) è vera per tutti k < n, allora P(n) è vera Conclusione: P(n) è vera
per tutti n ∈ ℕ
Esempi dove Serve Induzione Forte
Correttezza di Algoritmi Divide-et-Impera
MergeSort: Per dimostrare correttezza su array di taglia n, dobbiamo assumere correttezza su
sottoearray di taglia ⌊n/2⌋ e ⌈n/2⌉.
Fibonacci e Ricorrenze Multiple
T(n) = T(n-1) + 2T(n-2) + c
L'induzione normale non funziona perché dobbiamo ipotizzare forme per T(n-1) E T(n-2).

Alberi Binari e Proprietà Strutturali
Teorema: Un albero binario con n nodi interni ha n+1 foglie
Induzione Forte: Assumere vera per tutti gli alberi con meno di n nodi interni, poi considerare albero con
n nodi dividendo tra sottoalberi sinistro e destro.
Pattern di Riconoscimento
Usa Induzione Forte quando:
• Ricorrenze multiple: T(n) dipende da T(n-1), T(n-2), ecc.
• Algoritmi divide-et-impera: divisione in sottoproblemi non unitari
• Strutture dati ricorsive: alberi, grafi
• Dimostrazioni su insiemi infiniti: numeri primi, partizioni
Usa Induzione Normale quando:
• Ricorrenza singola: T(n) dipende solo da T(n-1)
• Progressione sequenziale chiara
• Proprietà numeriche semplici
